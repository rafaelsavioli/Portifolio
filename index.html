01 React

FluxoBoard

Dashboard financeiro pessoal com quadro Kanban de pagamentos. Front-end em React 18 com Vite, backend em Node.js e Prisma.

O problema
Organizar contas a pagar exigia planilha: sem histórico de status, sem fluxo de caixa e sem meta de economia acompanhada.
O que construí
Drag & drop entre Planned → Pending → Paid → Overdue com atualização otimista, CRUD com filtros combinados, metas com barras de progresso e autenticação JWT. Backend modular em camadas.
  • React 18
  • Vite
  • Tailwind
  • Node.js
  • Prisma

Visual Analyser
