01 React

FluxoBoard

Dashboard financeiro pessoal com quadro Kanban de pagamentos. Front-end em React 18 com Vite, backend em Node.js e Prisma.

O problema
Organizar contas a pagar exigia planilha: sem histórico de status, sem fluxo de caixa e sem meta de economia acompanhada.
O que construí
Drag & drop entre Planned → Pending → Paid → Overdue com atualização otimista, CRUD com filtros combinados, metas com barras de progresso e autenticação JWT. Backend modular em camadas.
  • React 18
  • Vite
  • Tailwind
  • Node.js
  • Prisma
  • Zod

03 Canvas API

Visual Analyser

Analisador de paleta e tom de pele que roda 100% no navegador, sem nenhuma API externa.

O problema
Descobrir tom de pele normalmente exige enviar a foto para um servidor externo.
O que construí
Análise de pixels com Canvas API, colorimetria e paleta dominante por median cut. Um quiz pontua o resultado e define o estilo pessoal.
