Projetos

FluxoBoard

React

Dashboard financeiro pessoal com quadro Kanban de pagamentos. Front-end em React 18 com Vite, backend em Node.js e Prisma.

O problema
Organizar contas a pagar exigia planilha: sem histórico de status, sem visualização de fluxo de caixa e sem meta de economia acompanhada.
O que construí
Drag & drop entre Planned → Pending → Paid → Overdue com atualização otimista, CRUD de transações com filtros combinados, metas com barras de progresso e autenticação JWT. Backend modular em camadas (routes → controller → service).
Decisões técnicas
Recharts para os gráficos, dnd-kit para drag & drop acessível por teclado, Zod para validação de request e tratamento de erro centralizado.
  • React 18
  • Vite
  • Tailwind
  • Node.js
  • Prisma
  • Zod

HazeWeb

Empresa própria

Sistema de gestão em produção que eu desenvolvo na HazeFlow, minha empresa. Roda para clientes reais.

O problema
Gestão de leads, projetos, processos e financeiro espalhada em planilhas e WhatsApp — sem histórico de mudanças e sem controle de quem alterou o quê.
O que construí
Sistema web com 23 telas e 22 APIs. Frente: HTML, CSS e JavaScript sem framework, com foco em acessibilidade. Back: PHP e MySQL com autenticação e controle de sessão.
O que aprendi na auditoria
Auditei o sistema inteiro e encontrei um vazamento real de dados: um usuário conseguia ver leads e potenciais de outro. Corrigi com filtros de dono em todas as consultas e affected-row no helper de banco, para a API parar de retornar sucesso sem alterar nada.

Visual Analyser

Canvas API

Analisador de paleta e tom de pele que roda 100% no navegador, sem nenhuma API externa.

O problema
Descobrir tom de pele e paleta dominante de uma imagem normalmente exige enviar a foto para um servidor — e um servidor externo.
O que construí
Análise de pixels com a Canvas API: extração do tom de pele, colorimetria e paleta dominante pelo método median cut. Um quiz pontua o resultado e define o estilo pessoal.
O que aprendi
Trabalhar com processamento de imagem sem sair do client-side: cada milissegundo de processamento acontece antes da pintura da tela.
  • JavaScript
  • Canvas API
  • Tailwind
  • Colorimetria
